one-line-pitches is a tiny program that writes one sentence to a file: a pitch to a friend who has never coded, asking them to describe the app idea they have talked about a dozen times to an agent in their own words, and be tapping a working first version tonight, with changing their mind costing nothing.

## Run it

```sh
python3 main.py
```

It writes the sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
